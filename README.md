La estructura de partición es la misma de siempre, pero aun así explicaré brevemente que hace lo creado hasta ahora:

---> Inex.html : Es la Landing page, es decir la parte mas cuidad esta fuera de una carpeta para que tenga mejor acceso a todo
---> style.css : Archivo con la estructura css basica para que sea comun en todas las páginas pero luego en la carpeta css poder hacer especificaciones para cada una.
---> script.js : Archivo con la estructura de javascript basica para que sea comun en todas las páginas pero luego en la carpeta js poder hacer especificaciones para cada una.
---> Carpeta IMG : Repositorio de imagenes almacenadas localmente.
