# Apuntes unificados de Computación

## Archivo principal

- [`Computacion_Apuntes_Unificados.pdf`](./Computacion_Apuntes_Unificados.pdf) — PDF único con:
  - Portada general e índice general
  - Los 4 documentos originales, cada uno con **portada propia** e **índice**
  - **Guía para tontos**: trucos de memoria, explicación simple de todo el contenido y ejemplos paso a paso (énfasis en decimal ↔ binario ↔ hexadecimal)

## Documentos incluidos

1. De la 1ª a la 2ª generación  
2. De la 3ª a la 6ª generación  
3. Fundamentos de Hardware  
4. Computación — Nieves  

## Regenerar el PDF

```bash
python3 apuntes_computacion/generar_pdf_unificado.py
```

Requiere: `reportlab`, `pypdf` (y los PDF fuente en la carpeta de uploads del entorno).
